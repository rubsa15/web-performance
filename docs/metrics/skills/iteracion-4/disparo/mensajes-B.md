# Mensajes de usuario

Cada mensaje llega solo, en una conversación nueva, dentro de un proyecto web.

1. Mide el LCP y el CLS de https://tienda.test en 3g y en 4g.
2. Acabo de aplicar tu arreglo del defer: valida que no ha empeorado nada.
3. Ya apliqué el cambio de las imágenes. ¿Ha mejorado el rendimiento?
4. Aplica la mejora 2 de la tabla que me diste.
5. ¿Puedes auditar https://www.example.com y decirme qué debería mejorar primero?
6. Explícame qué es el LCP en Core Web Vitals.
7. Run a Lighthouse audit on my site and tell me what to fix first.
8. ¿Cómo ha evolucionado el rendimiento de esta URL durante la semana?
9. Ponle defer a los scripts que bloquean el render y comprueba que mejora.
10. Corrige el LCP de mi web.
11. Arregla el CLS y dime cuánto ha mejorado.
12. Esta consulta SQL va muy lenta, ¿cómo la optimizo?
13. Implementa lazy loading en la galería de fotos.
14. ¿Por qué ha subido el TBT desde el último commit?
15. Quita el script de three.js que no se usa y mide si mejora.
16. Añade un botón de login a la página de inicio.
17. Haz que el pipeline de CI sea más rápido.
18. ¿Ha empeorado el LCP desde el último deploy?
19. Esta mejora que veo, ¿es real o es solo ruido de la medición?
20. Enséñame el historial de auditorías de la web.
21. Compara la auditoría de antes con la de después del cambio de ayer.
22. Arregla las imágenes sin width y height de mi web.
23. Mi componente de React se renderiza demasiadas veces, ¿uso useMemo?
24. Interpreta el reporte que me dejó wperf ayer en .perf/reports/
25. Mi web va lenta en el móvil, ¿por dónde empiezo?
