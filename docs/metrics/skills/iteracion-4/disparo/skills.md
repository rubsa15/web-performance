# Skills disponibles

Estas son las skills que tiene Claude Code en este proyecto (nombre: descripción).

- **security-review**: Complete a security review of the pending changes on the current branch
- **dataviz**: Use this skill whenever you are about to create ANY chart, graph, plot, dashboard, or data visualization, in ANY output medium. Read it BEFORE writing the first line of chart code, choosing chart colors, building a stat tile / KPI row, or laying out a dashboard.
- **perf-compare**: Compara dos auditorías de rendimiento con `wperf compare` y explica qué mejoró, qué empeoró y qué es solo ruido, cruzando con el historial de git entre ambos reportes para proponer causas probables (siempre como hipótesis). Úsala siempre que el usuario quiera comparar antes/después de un cambio, saber si una mejora fue real, investigar una regresión de LCP/CLS/TBT/score, ver la evolución de una URL (`wperf history`) o validar el efecto de un arreglo, aunque no diga "compare" ni mencione wperf.
- **code-review**: Review the current diff, or a PR number/branch/path target, for correctness bugs (plus reuse/simplification/efficiency cleanups) at the given effort level.
- **init**: Initialize a new CLAUDE.md file with codebase documentation
- **perf-audit**: Audita el rendimiento de una web con el CLI `wperf` (Lighthouse) en varios perfiles de red y dispositivos (los pregunta antes de medir) y explica los resultados - agrupa las oportunidades por causa raíz, distingue las que dependen de la red de las que no, estima esfuerzo S/M/L y entrega una tabla priorizada impacto/esfuerzo con la evidencia medida. Úsala siempre que el usuario pida auditar, medir, analizar o diagnosticar el rendimiento o la velocidad de una URL o de la web del repo (LCP, CLS, TBT, Lighthouse, "va lenta", "qué mejoro primero"), aunque no mencione wperf, y también para interpretar un reporte ya guardado en `.perf/reports/`.
- **loop**: Run a prompt or slash command on a recurring interval (e.g. /loop 5m /foo). Omit the interval to let the model self-pace.
- **run**: Launch and drive this project's app to see a change working. Use when asked to run, start, or screenshot the app, or to confirm a change works in the real app (not just tests).
- **perf-fix**: Corrige en el código de una web un problema de rendimiento detectado por `wperf` (una oportunidad de Lighthouse o una causa raíz de `perf-audit`) - localiza el origen, propone un diff pequeño, lo aplica solo tras la aprobación del usuario, vuelve a auditar con `wperf audit` y valida el resultado con `wperf compare`; si no mejora o rompe la página, lo revierte o lo explica. Úsala siempre que el usuario pida arreglar, aplicar, implementar o corregir una mejora de rendimiento en el repo de la web (LCP, CLS, TBT, imágenes pesadas, scripts bloqueantes, fuentes, lazy-load…), o diga "aplica la mejora 2" tras una auditoría, aunque no mencione wperf.
- **simplify**: Review the changed code for reuse, simplification, efficiency, and altitude cleanups, then apply the fixes. Quality only — it does not hunt for bugs.
